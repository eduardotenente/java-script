Sistema de pesquisa de CEP
Crie uma aplicação que permita consultar CEPs utilizando:

https://viacep.com.br/ws/CEP/json/

Requisitos:
- Crie um campo para digitar o CEP.
- Adicione um botão de pesquisa.
- Utilize Fetch API para realizar a consulta.
- Exiba o endereço, bairro, cidade e estado no HTML.
- Trate CEPs inválidos.
